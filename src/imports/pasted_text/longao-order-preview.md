Crie um **preview funcional, altamente apresentável e visualmente sofisticado de um sistema de pedidos desenvolvido especificamente para o LONGÃO**, cafeteria localizada na Vila Buarque, São Paulo.

Este projeto será apresentado diretamente para os responsáveis pela cafeteria. Portanto, o objetivo principal NÃO é construir um sistema completo de produção neste momento, e sim criar um **protótipo navegável extremamente convincente**, simples de entender e que demonstre claramente como o sistema poderia melhorar a operação do Longão.

## Referências da marca

Use estas referências para compreender a identidade do Longão:

* Instagram: https://www.instagram.com/_longao/
* Matéria: https://revistaespresso.com.br/cafeterias/cafeteria-une-cafe-e-corrida-na-vila-buarque-sp/

Caso seja possível acessar essas referências, analise principalmente:

* identidade visual;
* fotografia;
* tipografia;
* arquitetura;
* materiais;
* cores;
* comunicação da marca;
* relação entre café e corrida.

Não copie literalmente o Instagram ou qualquer site existente.

Crie uma interface original que pareça pertencer naturalmente ao universo do Longão.

---

# CONCEITO

O Longão conecta:

**CAFÉ ESPECIAL + CORRIDA + COMUNIDADE + CULTURA + DESCANSO**

O sistema deve refletir isso.

Evite totalmente a aparência de:

* ERP empresarial genérico;
* sistema antigo de restaurante;
* dashboard corporativo azul;
* SaaS com gradientes roxos;
* excesso de cards arredondados;
* interface cheia de gráficos desnecessários.

Quero algo com personalidade.

A interface deve transmitir:

**brutalismo refinado + editorial + running culture + specialty coffee + São Paulo**

Use como inspiração conceitual elementos presentes no espaço:

* concreto;
* arquitetura brutalista;
* ambiente urbano;
* discos de vinil;
* equipamentos de café;
* métodos manuais;
* cultura de corrida;
* números de prova;
* cronômetros;
* etiquetas;
* sinalização esportiva;
* jardim;
* sensação de laboratório de café.

Não transforme a interface em uma caricatura esportiva.

A corrida deve aparecer de maneira sutil e inteligente.

---

# IDENTIDADE VISUAL

Priorize uma estética minimalista, editorial e contemporânea.

Use:

* bastante espaço negativo;
* contraste forte;
* tipografia marcante;
* números grandes;
* linhas finas;
* divisórias;
* grids;
* pequenas informações técnicas;
* ícones minimalistas;
* animações discretas;
* imagens grandes apenas quando realmente ajudarem.

Prefira cantos retos ou levemente arredondados.

Evite componentes excessivamente "fofinhos".

A interface deve parecer criada por um estúdio de design para uma cafeteria independente de São Paulo.

## Tipografia

Use uma combinação semelhante a:

* fonte sans-serif moderna e limpa para interface;
* fonte condensada ou display para números, pedidos e títulos;
* fonte monoespaçada apenas para pequenas informações técnicas, timers e códigos.

A hierarquia tipográfica deve ser extremamente clara.

# RESULTADO ESPERADO

Quero que, ao abrir o projeto, a sensação seja:

**"Isso parece um sistema que já foi criado para o Longão."**

e não:

**"Isso parece um template de sistema de restaurante onde trocaram o logo."**

Priorize nesta ordem:

1. identidade do Longão;
2. clareza;
3. experiência de apresentação;
4. velocidade operacional;
5. acabamento visual;
6. funcionalidades.

O resultado final deve ser moderno, urbano, sofisticado, simples e memorável.
